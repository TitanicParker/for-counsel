# Machine-readable source manifest

**Status:** CONTROLLING — clerical infrastructure

`source-manifest.csv` is the machine-readable companion to `evidence/SOURCE_EXHIBIT_MANIFEST.md`. It begins with the source used for the EUID pilot and must expand source-by-source as transcription and pagination are verified.

Allowed `native_page_status` values are `UNMAPPED` or `VERIFIED`. A `VERIFIED` value requires a pagination-map record.
