Source-status discipline

Some repository pages are faithful redacted transcripts of originals; some are source-bundle indexes or abstracts; some reproduce older material inside later bundles. The original or native source controls wherever available. Repetition in a later institutional document is not counted as an independent historical evidential origin merely because it appears again.
