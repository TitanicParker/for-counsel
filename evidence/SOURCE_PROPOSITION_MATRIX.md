## Use rule

A controlling memorandum should not state a proposition more strongly than this matrix unless a new source is added, contrary material is addressed, and the matrix is updated first.

Where an issue is expert-dependent, documentary analysis may formulate the question but should not silently answer professional-standard, clinical-mechanism or strict but-for causation issues.
