# For Counsel

## Purpose

This repository is a counsel-facing evidential and analytical instrument concerning a young-onset movement-disorder case. Its job is to make the source record, source genealogy, disputed propositions, later revalidation, and outstanding evidence gaps easy to reconstruct without collapsing evidence into argument.

It is not a memoir, campaign page, pleading, or substitute for independent legal or medical advice.

## Current evidential boundary

The strongest present issue is not whether Liam had parkinsonism. The record strongly supports that he did.

The narrower issue is how a disabling bilateral foot/lower-limb phenomenon, whose relationship to the neurological syndrome was expressly left unresolved in the accessible 2017 record, moved into an operative podiatry pathway and was subsequently classified, treated, communicated, reconsidered, and relied upon.

The accessible record remains strong evidence of observed neurological signs, investigations, recorded reasoning, treatment choices, and the fact that podiatry became a disposition. It is not safely self-sufficient proof that the foot/lower-limb problem had been established as neurologically separate, that podiatry constituted neurological resolution, or that Liam accepted that transition.

Use the formulation:

> The accessible record does not demonstrate the reasoning bridge.

Do not convert that into:

> No reasoning existed.

The latter is not established.

## Repository structure

### `docs/`

Counsel-facing HTML site and navigation. The substantive public/counsel pages live here. Small root-level HTML files are compatibility redirects into this directory and should not be mistaken for duplicate substantive pages.

### `docs/source-records/`

Stable redacted source reproductions and source extracts. These are evidential materials, not argument pages. They should preserve provenance and should not be edited merely to improve the case presentation.

Source records already materialised include 2017 clinical material, longitudinal neurology records, the March 2025 complaint, clinician/regulatory correspondence, GDPR requests and decisions, governance material, and decision-provenance records. See the source-record README and the evidence inventory for the current list.

### `evidence-audit/`

Reproducibility and source-control layer. It contains the inventory, genealogy, acquisition status, source packs/chains, migration/structure notes, and the knowledge-and-gaps register.

### `PROJECT_ORIENTATION.md`

The repository front door for substantive evidential orientation. It should remain aligned with the source inventory and should yield to new primary evidence.

## Source-handling rules

1. Keep source evidence separate from analysis.
2. Count independent evidential origins, not the number of later documents repeating a proposition.
3. Link material propositions back to the best available source.
4. Preserve adverse and qualifying evidence.
5. Mark patient evidence, clinical opinion, inference, derivative institutional conclusions, expert questions, and unknowns distinctly.
6. Do not back-project later evidence into an earlier clinical knowledge state.
7. Do not describe a missing source as non-existent merely because it has not been located.
8. Do not use an institutional conclusion as independent corroboration unless its source architecture shows genuinely new evidential work.

## Key current gaps

The highest-value outstanding materials remain the complete PAR and SIMT source bundle, native 2017 EHR/version metadata, Complex Case Meeting and Monaghan/Counihan/Healy provenance material, trainee/witness evidence concerning the reported bedside interaction, Article 18 operational routing/audit records, and the original/complete podiatry pathway.

These are evidence-acquisition targets, not assumptions about what the missing records will show.
