# Source Genealogy and Independent-Origin Audit

The purpose of this file is to prevent document count from being mistaken for evidential independence. Each proposition is traced from its earliest evidential origin through later reference, summary and governance use. A later document is counted as a new evidential origin only if it adds evidence not merely copied, restated or accepted from the same upstream source.

## Genealogy key

- **Origin:** earliest source capable of proving the proposition at the level stated.
- **Later reference:** later source that refers to the proposition.
- **Later summary:** a complaint, clinician response, project page or institutional summary.
- **Governance use:** PAR/SIMT/QPS/regulatory use, where shown.
- **Current authority:** what the proposition can safely carry now.
- **Independent-origin count:** count of genuinely independent evidential roots, not documents.

# Central genealogy finding

By contrast, the propositions that would close the disputed historical transition — feet established as separate, podiatry as neurological resolution, global patient agreement, and independent SIMT revalidation of those propositions — have either no demonstrated independent origin or an unknown source architecture because the relevant institutional materials are missing.
