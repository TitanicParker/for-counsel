# Archived first-generation counsel presentation

This directory preserves the counsel-facing presentation that was on `main` before the August 2026 evidence-architecture rotation.

**Preserved from:** `main` at commit `6be1e1580b257ed47cfbf475fe05dfd3a7ab7f40`  
**Archive created:** 11 August 2026  
**Status:** superseded presentation/analysis; retained for provenance.

The archive is not a primary evidence source. It preserves the language, structure and conceptual framing of the earlier site so that later changes can be understood and audited.

The first-generation presentation contained several useful human-facing ideas, including the distinction between hindsight misdiagnosis and a later reopening/corrigibility question. It also contained formulations that were more conclusive than the subsequently developed source genealogy and fact architecture safely support. Later pages may reuse or adapt earlier language only after revalidation against the controlling sources and fact register.

## Preserved material

- `README.md` — former root repository orientation
- `root/` — former root-level entry/compatibility pages, including the former GDPR/incorrigibility presentation
- `docs/` — former counsel-facing site pages
- `docs/assets/css/styles.css` — stylesheet used by the archived presentation

Primary medical and correspondence source records are **not duplicated into this archive**. They remain in the live `docs/source-records/` library. This avoids creating two competing evidential corpora.

Some archived HTML links were authored relative to their former live location and therefore may point to paths that are no longer local to the archive. The archived files are preserved as artefacts rather than rewritten to conceal that historical structure. The live source library remains the controlling route for source documents.

## Rotation principle

The successor presentation is being built under `agent/counsel-site-rotation` using the sequence:

**SOURCE → FACT → PROPOSITION → PROSE**

The old public paths will not intentionally be removed without a verified archive destination and a replacement or compatibility route. See [`ROTATION_PLAN.md`](../../ROTATION_PLAN.md).
